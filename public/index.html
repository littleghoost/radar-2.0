O que mudou nesta versão

›_ Atualizar pelo PowerShell Windows 10/11

Copie o comando e cole no PowerShell. Ele baixa, verifica e instala a versão nova, fechando o Radar automaticamente quando as buscas terminarem.

O atualizador aguarda as buscas terminarem antes de fechar o Radar. Em versões antigas, o encerramento usa o modo de compatibilidade após verificar que não há buscas ativas. Se não for possível verificar, a instalação é cancelada para proteger os dados.
O botão de download abre o instalador no navegador. O comando PowerShell permite instalar sem passar pelo assistente; seus radares e anúncios ficam salvos no banco de dados local.
